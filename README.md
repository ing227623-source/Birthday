# Tanishka Birthday — Ultra Premium Edition

A polished, mobile-first birthday mini experience for Tanishka.

## Features
- Floating pink/purple aurora background and particle field
- Custom detailed SVG kitty with gradients, shadows and highlights
- Smooth page transitions and subtle 3D card tilt on desktop
- Fixed pink/white Back button with safe spacing from the centered TANISHKA header
- Animated 3D-style birthday cake and candle
- Original lightweight ambient audio (`ambient.wav`)
- Interactive questions and playful No button
- Butterfly-catching mini game
- Celebration sound + large confetti reveal
- Responsive design for phones and desktop

## GitHub Pages
Upload all files in this folder to the repository used for the birthday site. Keep `ambient.wav` in the same folder as `index.html`.
