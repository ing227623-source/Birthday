# Tanishka Birthday Website 💜

A ready-to-upload static birthday website for GitHub Pages.

## Files
- index.html — page structure
- style.css — pink/purple glowing design
- script.js — navigation + live sparkle background
- game.js — 3-level birthday puzzle game
- assets/ — reserved for optional custom assets

## GitHub Pages
1. Create a new GitHub repository.
2. Upload every file and folder from this ZIP.
3. Make sure `index.html` is in the repository root.
4. Open Settings → Pages.
5. Select the `main` branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

No external audio file is required: the final birthday chime is generated by the browser using Web Audio.
